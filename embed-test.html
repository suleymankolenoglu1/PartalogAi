Partalog Host Test Sayfasi

Bu sayfa ayrica bir e-ticaret sitesi kurmadan hedef bazli embed, host adapter ve event-driven akislari test etmek icin hazirlandi. Secilen parca aksiyonlari sag tarafta host site gibi simule edilir.

Nasil Kullanacaksin

Ilk asamada sadece embed key degistirmen yeterli.

Test Host
1. Panelden bir embed olustur Onerilen: `Host Site Islemi` + `Sitede Ara` veya `Custom Handler`.
2. Bu dosyada sadece `EMBED_KEY` degerini degistir Asagidaki script icinde bulunan `emb_xxx` degerini panelden gelen embed key ile degistir.
3. Domain allowlist'e bu hostu ekle Ornek: http://127.0.0.1:5500 veya kullandigin baska local origin.
4. Sayfayi local server ile ac Dosyayi `file://` olarak degil farkli bir porttan servis ederek ac.
Test edilen akışlar Embed + Availability + Search + Product + Cart
Gerekli olan tek bilgi Panelden aldigin `embedKey`
Bu dosya window.PartalogHostConfig uzerinden host siteyi taklit eder. Yani yeni endpoint yazmadan once event-driven modelin calisip calismadigini burada gorebilirsin.
